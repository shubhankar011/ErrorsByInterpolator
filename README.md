# ErrorsByInterpolator

A research project studying the error introduced by linear interpolation when approximating square roots between perfect squares.

## Project overview

This repository contains:

- `research/paper.tex` — the LaTeX source for the paper titled *"The Illusion of Linearity Between Perfect Squares"*.
- `src/mapping.py` — a Python script that implements and compares two square-root approximation methods.
- `Comparison.png` — the plot generated by `src/mapping.py` comparing interpolation-based results with the Babylonian method.

## Research focus

The paper analyzes how linear interpolation (Lerp) behaves on the function `f(x) = \sqrt{x}` when evaluated between perfect square values.
It examines the discrete differences of `x^2` and `\sqrt{x}`, demonstrates why the square function is parabolic, and explains why interpolation is structurally insufficient for non-linear functions.

## Paper details

- Title: "The Illusion of Linearity Between Perfect Squares"
- Authors: Shubhankar Kumar & Virat Dixit
- Date: April 2026

## Source code

`src/mapping.py` contains:

- `approx_sqrt(i)` — computes an approximate square root using linear interpolation between nearest perfect squares.
- `approx_sqrt2(i)` — computes an approximation using an iterative Babylonian method.
- A plotting section that generates `Comparison.png` for visual analysis.

## Usage

Run the script from the repository root:

```bash
python src/mapping.py
```

This will generate `Comparison.png` showing how the two methods compare over the sample range.
